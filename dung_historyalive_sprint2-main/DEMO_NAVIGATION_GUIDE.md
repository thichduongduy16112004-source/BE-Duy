   - Returns to Home Screen

3. **▶️ Play Button** (Video Center)
   - Play/pause video (demo: console log)

   - Shows video progress (yellow = watched)

   - Correct answer shows in green
   - Wrong answers stay gray

7. **Submit Button** (Bottom)
   - Click "XÁC NHẬN & TIẾP TỤC"
   - **If correct:** Continue to next question
   - **If wrong:** Navigate to Wrong Answer Screen

## 🐛 Troubleshooting

### Issue: Screen doesn't navigate
**Solution:** Check console for errors, ensure route exists in `/src/app/routes.tsx`

### Issue: Buttons don't respond
**Solution:** Verify `onClick` handler is attached, check `data-name` selectors

### Issue: Figma component not loading
**Solution:** Confirm import path, check if file exists in `/src/imports`

### Issue: Layout broken on mobile
**Solution:** Ensure wrapper div has `w-[402px] h-[874px]` classes

### Issue: Images not showing
**Solution:** 
- Check if using `figma:asset` scheme correctly
- Verify SVG imports use relative paths
- Don't prefix `figma:asset` with `./` or `../`
